# ADR-0008: Рендиції генеруються одразу за версіонованими пресетами

**Статус:** Accepted

## Контекст
On-the-fly трансформації (як у Cloudinary/imgproxy) вимагають сервера трансформацій на шляху читання та зберігання оригіналів, що суперечить ADR-0004/0005 і меті мінімального зберігання.

## Рішення
- Під час обробки генеруються всі рендиції, визначені версією пресету.
- Версії пресетів незмінні; зміна параметрів = нова версія; переобробка — явна дія (`/reprocess` або масова задача з адмінки) і створює новий Blob з новими URL.
- Оригінал зберігається лише якщо пресет має `retainOriginal: true`.

## Наслідки
- Видача — чисті статичні файли з CDN, `immutable`.
- Новий розмір для фронтенду потребує нової версії пресету + переобробки (або збереження оригіналів).
- Шлях до рендицій на вимогу (M5): lazy-генерація з кешуванням у R2 для пресетів, які зберігають оригінали.
